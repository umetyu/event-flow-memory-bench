# 実施順序

実装完了と実データでの検証完了は別です。

| 段階 | 実装 | 実データでの完了条件 |
|---|---|---|
| 0: 環境・データ | HDF5検査、split、出典固定 | データ取得、元記録group、GPUを確認 |
| 1: 論文再現 | 重み読込、dt1/dt4、表との差分 | RecEVFlowNet / FireNetの4系列の再現 |
| 2: pilot | 5条件 × 3 seeds | FireNet系の収束・評価 |
| 3: 主対照 | [56]は報告値8条件を収録済み、UZH再学習版は実装待ち。既存5条件gridは後続の要因比較用 | [56]の報告値とUZH再学習結果を区別した比較表 |
| 4: 履歴 | 4履歴 × 5条件 × 3 seeds | 固定anchorで曲線作成 |
| 5: AffineObjects | 共通proxy、LayerSeg、mask評価 | 同一窓のFWL/RSAT、IoU/DR |
| 6: SNN | 8モデルの設定・読込 | 必要なモデルの再現・比較 |
| 7: Hebbian | 接続位置・対照を設計 | 更新則を確定し実装・比較 |

jobs.jsonは実行順序を保持し、run_grid.pyは失敗時に停止します。latest.ptはepoch境界の再開用、best.ptは検証RSATで選択した評価用です。

比較対象は表の2・4・5・6行目です。現在は既報値・配布重みを使い、2行目の[56]だけUZHでの再学習条件も追加します。他モデルの再学習はこの段階では投入しません。生成済みgridは既存5条件で、[56]は別途実装が必要です。[対象と状態](BASELINES.md)。FireNet系を先行確認に使い、全14モデル・SNN一括学習は行いません。

実施済み: 既存の著者UZH/MVSECの検査、記録単位split生成、著者配布2モデルの重み取得、V100上でのFireNet / RecEVFlowNetの短時間学習速度計測。[詳細](IZAR.md)。

配布2モデルのMVSEC評価は完了。AEEは全16条件で許容差内ですが、dt4の外れ値率2条件が未一致のため、段階1の完全再現は未達です。Step 2の本学習はまだ投入していません。

未実施: 全条件の本学習、統計的結論、Hebbian更新則。速度計測や合成テストの値を精度の研究成果として報告しません。
